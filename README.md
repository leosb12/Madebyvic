# Made By Vic

**Made By Vic** is a modern digital portfolio and content management website developed for an independent artist. The platform showcases artwork, services, murals, commissioned pieces, and digital design work through a visual-first interface.

In addition to the public-facing website, the project includes an **administrative dashboard that allows the site owner to manage and update the website content without modifying the source code**.

## Overview

The goal of the project was to create a professional online presence that combines an art portfolio with an easy-to-manage content platform.

The website presents the artist's work through a responsive dark-themed interface designed to give strong visual emphasis to images and artwork.

## Key Features

* Responsive digital art portfolio
* Artwork and gallery presentation
* Dedicated sections for:

  * Canvas Art
  * Commissioned Art
  * Mural Art
  * Digital Design
* Services presentation
* Contact section for potential clients
* Dynamic website content
* Administrative authentication
* Editable content directly from the website
* Centralized administration dashboard

## Admin Dashboard

One of the main features of the project is its **content management functionality**.

Authorized administrators can manage the website through a dedicated dashboard and update different sections of the platform without having to manually edit the application code.

The administration tools allow the site owner to maintain the website independently and keep the portfolio updated as new artwork and services are added.

Examples of manageable content include:

* Images
* Gallery items
* Service information
* Titles and descriptions
* Portfolio content
* Website sections

This approach transforms the project from a static portfolio into a **maintainable web platform designed for real-world use**.

## User Experience

The interface was designed around the artist's visual identity, using a minimalist dark aesthetic that keeps the artwork as the main focus.

Navigation provides direct access to the main sections of the platform, including services, gallery, contact information, digital design, murals, and administrative functionality.

## Technologies

* JavaScript
* Web development technologies
* Responsive UI design
* Dynamic content management
* Administrative dashboard

## Project Highlights

This project involved more than creating the visual interface of a website. It required designing a solution that could be maintained by the final user after deployment.

The combination of a public portfolio and an editable administration system provides the artist with a platform that can evolve as new projects, artwork, and services are created.

## Purpose

Made By Vic was developed as a real-world web solution focused on:

* Presenting an artist's professional portfolio
* Improving the visibility of services and artwork
* Providing an intuitive experience for visitors
* Allowing the website owner to manage content independently
* Reducing the need for technical intervention when updating the site
